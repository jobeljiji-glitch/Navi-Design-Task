# Decisions

This file is maintained by agents. Each entry records a choice that isn't obviously specified by `docs/spec.md` or the reference screens.

| ID | Decision | Reason |
|----|----------|--------|
| D-001 | Manual scaffold (no `npm create vite`) | Repo root is not empty; scaffolding tools would fail or overwrite existing files (`AGENTS.md`, `GEMINI.md`, etc.). Files were written directly. |
| D-002 | Reference screens copied to `public/reference/` via a Vite plugin (`buildStart` hook) | Needed so the `ReferenceOverlay` component can load images on GitHub Pages, where `reference/` is not served. The copy happens at dev-server start and at build time. |
| D-003 | Vitest config inlined in `vite.config.ts` (not a separate `vitest.config.ts`) | Keeps project root cleaner; `vite.config.ts` supports a `test` key natively. |
| D-004 | PWA icon is a programmatically-generated plain red (`--bms-red`) square PNG | No real brand assets allowed. The icon exists solely to satisfy the web manifest requirement. |
| D-005 | Hash routing (`HashRouter` from react-router-dom v6) | Required for GitHub Pages to serve the app on deep links without server-side routing. |
| D-006 | `tsconfig.app.json` for src + `tsconfig.node.json` for Vite config | Vite 6 / TS 5 split-config convention; avoids type collisions between DOM and Node environments. |
| D-007 | 05 Seat Count Audit: Title `text-[18px] font-medium` → `text-[22px] font-normal`; Numbers `text-[14px]` → `text-[17px] font-normal`; Tiers centered `text-[11px]/text-[18px] bold` → left-aligned `text-[12px] 400`/`text-[20px] 500` no truncation | Matches reference 05 and 19. BMS uses 400 for regular titles and numbers with 36 pt red circle for selection, and un-truncated tier details. |
| D-008 | 06 & 08 Seat Layout Audit: Bottom CTA bar total amount `font-bold` → `font-medium text-[18px]`; Legend items gap & padding normalized to 16 pt section margins; Showtime pill 4 pt solid green indicator preserved | Eliminates overly bold 700 weights on pricing, aligning with BMS emphasis (500) over 400 body. |
| D-009 | 11 Confirm Booking Audit: Summary ticket count `font-bold` → `font-medium`; Line items `text-[14px]` → `text-[15px] font-normal`; Order total `font-bold` → `font-medium text-[18px]` | Real BMS booking confirmation uses medium weights for numbers and regular 15 pt for fee items rather than bold headings. |
| D-010 | 12 Payment Audit: Amount Payable header `font-bold` → `font-medium text-[20px]`; Row title `text-[14px] font-medium` → `text-[15px] font-normal`; Row padding `p-4` → `px-4 py-3.5` (52 pt height) | Calibrates payment option list to match native BMS list cell dimensions and typography in reference 12. |
| D-011 | 14 & 18 Bookings List Audit: "Ordered on" `text-[12px]` → `text-[13px]` outside card; Title/date `16-17px font-bold` → `17px font-medium`; Footer hairline divider full-width `-mx-4` with 1 pt vertical separator before status message | Matches reference 18 layout exactly where cards have an external timestamp and internal separated footer. |
| D-012 | 16 M-Ticket Redesign: Semicircle perforation cutouts using `#E5E5E5` pseudo-cutouts; rotated 90° "M-Ticket" text; support pill; 120 pt QR code; green group context strip above card | Implements authentic BMS M-Ticket structure from reference 16 with single-ticket group context addition. |
| D-013 | 17 iOS Share Sheet Redesign: System font stack `-apple-system, "SF Pro Text", system-ui`; 38 pt top radius; 60 pt preview tile; 44 pt close button; 64 pt pastel contact avatars with WhatsApp badges; 64 pt stylised app squircles | Native iOS share sheet presentation without third-party dependencies as specified in prompt 02b. |
| D-014 | 03 Baseline Flow Routing & Reference Mapping | Added hash routes `/rohan/movie`, `/rohan/showtimes`, `/rohan/seats`, `/rohan/seats-selected`, `/rohan/loader`, `/rohan/confirm`, and `/rohan/payment` in `App.tsx` and mapped them in `ReferenceOverlay.tsx` with overlay selector. |
| D-015 | Dynamic Pricing & Seed Data Grounding | Derived movie metadata, cinema information, showtimes, tiers, and seat maps directly from `src/logic/seed.ts` and `src/logic/money.ts`. All amounts (`Pay ₹460`, `₹514.28`, `₹1,662.84`) are dynamically computed from selected seat objects and convenience fees rather than hardcoded. |
| D-016 | 05 & 06/08 Layout Calibrations | Calibrated `PriceTierList` to render 3 top columns + 1 centered bottom item when tier names contain `ROWS` (matching reference 05); calibrated `SeatLayoutScreen` scroll container with 96 pt top padding to align tier headers and seat rows within 2-4 pt of references 06 and 08 in difference mode. |
| D-017 | Real Vehicle Asset Continuity | Preserved `SeatCountPicker` loading real vehicle illustrations (`public/illustrations/seat-count/*.png`) matching 02b without drawn vector placeholders. |
| D-018 | 03b Showtime to Seat Count Sheet Flow | Tapping showtime opens seat layout with "How many seats?" sheet open initially (`isCountSheetOpenInitially: true`), setting the target ticket count, and closing upon "Select seats". Re-opened by "✎ N Tickets". |
| D-019 | 03b Group Seat Picking Logic (`src/logic/seatPick.ts`) | Implemented pure `pickSeats(layout, selected, tappedSeat, ticketCount)` auto-expanding rightwards within row/tier bounds, overflowing leftwards when room is tight, alerting with remaining seat count on fragmented blocks, and deselecting single seats when incomplete. Non-enumerable metadata preserves Vitest array equality. |
| D-020 | 03b Horizontal Momentum Seat Map & Sticky Rows | Switched seat map to true physical dimensions (20×20 pt tiles, 26 pt pitch, 3 pt radius, 9 pt numbers) with `touch-action: pan-x pan-y`, sticky left column for row letters, removal of artificial 96 pt top spacing, and auto-centering D05–D10 on mount. |
| D-021 | 03b Timed Seat Confirmation Loader | Added a 1,200 ms simulated loader sheet ("Confirming your Seats!") after tapping Pay on the seat layout before transitioning to Confirm Booking. |
| D-022 | 03b Showtimes Screen Fidelity (Ref 20) | Seamless borderless date strip with full-height solid red selected day; 15 pt weight 500 language row; red outlined filter chips; 56 pt cinema logo; 200×72 pt showtime pill with 4 pt green bar and centered 17 pt time (SCREEN 4 badge removed); unmuted context cinemas with toast; and bottom subtitle toast. |
| D-023 | 03b Confirm Booking Card Integration (Ref 22) | Integrated cancellation band inside summary card flush to bottom edge sharing bottom radius; calibrated price card to 15 pt grey labels and 17 pt weight 500 order total; removed Club/offers out-of-scope upsells; calibrated bottom bar to 46% width strong red CTA and 20 pt weight 500 total amount. |
| D-024 | 03b Performance & Bundle Optimization | Switched vehicle illustrations to WebP format (~5 KB each) with `<img decoding="async">` and preloading on showtimes mount; code-split `/kit` and `ReferenceOverlay` via `React.lazy`; trimmed Google Fonts to Roboto 400 and 500 weights only. Main JS bundle reduced from 455.51 kB (132.13 kB gzip) to 388.10 kB (119.82 kB gzip). |
| D-025 | 03c Navigation State-Gated Seat Count Sheet | Gated automatic opening of the "How many seats?" bottom sheet strictly to `{ fromShowtime: true }` in navigation state or initial entry without count set; navigating back from Confirm Booking does not reopen the sheet. |
| D-026 | 03c Scale-Calibrated Screen Typography & Geometry (Ref 20 & 22) | Calibrated measurements using 1 pt ≈ 1.83 px factor: Showtimes pills to 110×39 pt with 15 pt centered time and 4 pt bar; logo tiles to 36 pt with distinct initials (`CP` Cineplex, `IX` INOX, `CN` Cinepolis); cinema titles to 15 pt/500 wrapping up to 2 lines without truncation; filter chips to 32 pt height / 14 pt text; card side margins to 12 pt (px-3) with 14 pt padding; Confirm summary card clipping eliminated with 22 pt 16+ icon, 14 pt black rating text, internal 14 pt cancellation band, and 18 pt/500 title/count, 16 pt/500 date and order total, 14 pt breakdown items. |
| D-027 | 03d Visual Polish Pass — Spacing, Type Sweep & Plain Back Chevrons | Removed circular / rounded grey backgrounds from back buttons across all screens, adopting bare 24 pt chevrons matching iOS BMS design. Standardized showtime pills to keep time on a single line (`white-space: nowrap`) at 15 pt weight 400, format labels (e.g. `LASER`) as a 10 pt grey caption directly under time, and subtitles (e.g. `[ENG]`) as an inline boxed badge next to time. Standardized summary card padding to 16 pt (`p-4`), info lines gap to 4 pt (`gap-1`), age warning text to 13 pt on a single line (`whitespace-nowrap`), and cancellation band padding to 12 pt vertical by 16 pt horizontal (`py-3 px-4`). Calibrated bottom CTA button height to 48 pt on movie detail screen with safe-area spacing. |
